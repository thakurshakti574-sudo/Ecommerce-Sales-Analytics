# E-Commerce Sales Performance Analytics 📊

### 🎯 Project Overview
This project focuses on analyzing e-commerce sales and transaction data to track key performance indicators (KPIs) and business revenue trends. It demonstrates an end-to-end data analytics workflow.

### 🛠️ Tech Stack & Workflow
1. **Data Extraction (SQL):** Extracted raw transaction and customer data from relational databases using optimized SQL queries (`sales_queries.sql`).
2. **Data Cleaning (Python):** Handled missing values, removed duplicates, and corrected data types using Pandas and NumPy (`data_cleaning.py`).
3. **Data Visualization (Power BI / Tableau):** Modeled the cleaned dataset locally to design interactive reporting dashboards. 

---

### 📊 Dashboard Wireframe & Metrics Layout
*Note: To maintain data governance and local system privacy, the metrics and chart structures developed in the desktop visualization environment are mapped below:*

| KPI / Metrics Block | Trend Analysis Chart | Segment Breakdown |
| --- | --- | --- |
| **Total Revenue:** Monthly Target vs Actuals | Line Chart: Month-on-Month Revenue Growth | Bar Chart: Top 5 Performing Product Categories |
| **Total Orders:** Active Orders Count | Bar Chart: Quarterly Order Volumes | Donut Chart: Customer Demographics Breakdown |
| **Average Order Value (AOV):** Order Basket Value | KPI Cards: High-margin Sales vs Targets | Table: Inventory Low-Stock & Supply Alerts |
